## 📂 Projects

### 🩺 [Breast Ultrasound Classification — Explainable AI](https://github.com/Sadhin404/Deep-Learning-Project/tree/main/Breast%20Ultrasound%20Classification)

An explainable deep-learning system that classifies breast ultrasound images as **Normal**, **Benign** or **Malignant** using **EfficientNet-B0** with transfer learning — and explains every decision with **Grad-CAM** heatmaps.

![Accuracy](https://img.shields.io/badge/Test_Accuracy-92.31%25-0e7490?style=flat-square)
![F1](https://img.shields.io/badge/Macro_F1-92.46%25-7c3aed?style=flat-square)
![Dataset](https://img.shields.io/badge/Dataset-BUSI_780_images-334155?style=flat-square)

📓 Notebook · 💻 Full code · 📄 Thesis paper · 🎯 Trained model · 📊 Results — everything inside the project folder, with a step-by-step [run guide](https://github.com/Sadhin404/Deep-Learning-Project/blob/main/Breast%20Ultrasound%20Classification/HOW_TO_RUN.md) so anyone can reproduce it.
