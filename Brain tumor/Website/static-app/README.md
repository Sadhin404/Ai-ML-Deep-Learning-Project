# Brain Tumor MRI AI — Explainable Classification

Upload a brain MRI image and get an explainable AI analysis in your browser:
a DenseNet-201 model classifies the scan as **Glioma**, **Meningioma**,
**Pituitary** or **No Tumor**, Grad-CAM shows where the model looked, and a
full PDF report can be downloaded.

- Test accuracy **99.47%** · macro F1 **99.46%** on 1,311 held-out test images
- Model runs 100% in the browser (ONNX Runtime Web) — images never leave the device
- Dataset: Brain Tumor MRI Dataset — Nickparvar, Kaggle

CSE, First Capital University of Bangladesh.

⚠️ Research & education tool — not a medical diagnosis.
